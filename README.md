# Luxury Jewelry Price Predictor 💎

## Overview
This project predicts the resale price of luxury jewelry based on features like brand, material, condition, and more. It uses machine learning to help collectors and buyers estimate the market value of items.

## Goals
- Explore factors that influence jewelry resale prices
- Train a regression model to predict price based on item attributes
- Visualize and interpret model performance

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Jupyter Notebook
